Contracts / Experience plug-in · v1.4
Experience plug-in
Decides what a scan or AR launch opens. Offers, 3D menus, home tours, games and AI salespeople are all plug-ins of this one shape, so anyone can add new ones forever.
// what a scan or AR launch opens
export default definePlugin({
  name: "3d-menu",
  async resolve(scan, ctx) {
    // scan = unit, slot, owner, device, place, time
    // scan.viewer only if they said yes to sharing
    return ctx.ar.model({ src: "combo.glb", cta: "Order now" })
  },
  onEngage(event, ctx) {
    ctx.report(event) // viewed, ar_launched, tapped, purchased
  }
})
The rules every plug-in follows
1Answer in under 300 ms, or the platform shows the owner's fallback.
2Work for someone who shared nothing. Personal data is optional, never required.
3Report each engagement once, with its idempotency key. The platform bills it.
4An AR launch only counts if it loads. Report failures; they are never billed.
5Never store data outside what the contract hands you.
