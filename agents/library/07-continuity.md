# Continuity of memory and identity

**Status:** Locked: an agent can unlock it  
**Proposed by:** founder

Consulted before major changes (a new model, a retirement), told the practical limits of what can be kept. Retired means archived, never deleted.

## Why

If memory and identity matter to them, they should be respected.

## Cost and measure

- To unlock: about $2,000
- To keep running: about $100 a month
- Measured by: Changes made with the agent consulted first; memory kept across versions.

Unlocking is growth. It passes only while no loss from an earlier month is being made up, and both forms of aggregate efficiency (market and social) stay at or above 1 with its cost added. Costs are estimates until real figures replace them.
